# comp1004---main-assignment-liam-emery 
Card Game
Module: COMP1004 Computing Project
Stand-up Meeting Leader: LA
Author: Liam Emery

Project Vision: Users should be able to manipulate cards around the screen. This includes using the mouse to drag and drop cards to any location on the screen, as well as be able to click cards to flip them over, whether from back to front or vice versa. It also should allow them to click a button to shuffle all the cards and reset them to the top left of the screen.

Overview: The project is card board where a standard card deck can be freely manipulated, flipped and shuffled into a random order via a button. The project was created using an Agile methodology, using sprints.
